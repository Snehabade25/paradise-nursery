# Paradise Nursery Shopping Application

A responsive online houseplant shop built with React, Redux Toolkit, React Router, and Vite.

## Features
- Welcome landing page and company information
- 18 houseplants arranged in three categories
- Add-to-cart buttons and a dynamic cart count
- Increase/decrease quantity and remove items
- Per-item subtotals and a grand total
- Responsive navigation and layout
- Checkout placeholder message

## Run locally
1. Install Node.js (LTS) from https://nodejs.org/
2. Open a terminal in this project folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Main assignment files

## Notes
Product images are loaded from Unsplash URLs and therefore require an internet connection. This is an educational demonstration; checkout is not connected to a payment provider.
